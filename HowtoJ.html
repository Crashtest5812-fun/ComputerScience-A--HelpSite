How to Java

This section provides guidance on how to write and understand Java code.

Getting Started

To begin coding in Java, you will need to set up your development environment.

  1. Install Visual Studio Code (VS Code) from the official website: https://code.visualstudio.com/ Or you can use Github: https://github.com to use Github Codespaces, which allows you to code in the browser without installing anything on your local machine.
  2. Create a new Java project in VS Code. You can do this by opening VS Code, selecting "File" > "New Project", and choosing "Java" as the project type. Follow the prompts to set up your project structure. If you are using Github, you can create a new repository and create a new codespace for your Java project. Github Codespaces uses VS Code in the browser, so you can code without installing anything on your local machine.
  3. Install the Java Extension Pack in VS Code. Go to the Extensions view by clicking on the Extensions icon in the Activity Bar on the side of the window. Search for "Java Extension Pack" and make sure it is made by Microsoft, Then click "Install". This extension pack includes essential tools for Java development, such as language support, debugging, and testing.
  4. Write your first Java program. In your project, create a new file with a .java extension (e.g., HelloWorld.java). Open the file and write the following code: 
    public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
  5. Run your Java program. You can run your program by right-clicking on the file in the Explorer view and selecting "Run Java". Alternatively, you can use the terminal to navigate to your project directory and run the command `javac HelloWorld.java` to compile the code, followed by `java HelloWorld` to execute it. If you are using Github Codespaces, you can also run your program in the terminal provided in the browser.

By following these steps, you will be able to set up your Java development environment and start writing and running Java code. Happy coding!

How It Works

Java uses different syntaxes, logics, and object-oriented programming pillars. These include:

Core Sytaxes & Stuctural Components

  1. Classes & Objects

    Java Uses Classes and Objects as blueprints (Classes) and real world instances (Objects). Java is strictly object-oriented• , meaning almost all code must live inside a class.

  2. Methods

    Methods are blocks of code that perform specific actions or functions when called.

  3. Variables

    Variables are named storage locations in memory used to hold data during execution.

  4. Data Types

    Classifications of data, split into primitives (like int for integers, double for decimals, boolean for true/false) and reference types (like String or custom objects).

Logic & Control Flow

  1. Operators

    Symbols used for math, comparison, and logic (e.g., +, -, ==, &&, !)

  2. Conditional Statements

    Decisions paths like if, else if, else, and switch that dictate which code executes.

  3. Loops

    Structures for repeating code blocks, including for, while, and do-while loops.

Object-Oriented Programming (OOP) Pillars

  1. Inheritance

    Code reusability allowing one class to adopt the attributes and methods of another (extends)

  2. Polymorphism

    The ability for a single action to behave differently depending on the object performing it (method overriding and overloading).

  3. Encapsulation

    Hiding sensitive internal data by making variables private and providing access through public getter and setter methods.

  4. Abstraction

    Hiding complex implementation details using abstract classes and interfaces.
